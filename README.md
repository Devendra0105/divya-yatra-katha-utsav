Create an immersive, cinematic, royal Jagannath Puri invitation.

Reference the interaction style of premium invitation websites:
- Full-screen animated opening with lotus mandala background.
- An elegant slide-to-open or tap-to-enter interaction.
- Layered atmospheric backgrounds featuring the provided lotus mandala background image.
- Beautifully composed devotional styling.
- Smooth transitions between sections.
- Ornamental visual separators.
- Large photographic sections.
- Elegant scroll-reveal effects.
- Premium closing screen.

VISUAL IDENTITY:
- Jagannath Temple-inspired artwork.
- Odisha Pattachitra decorative elements.
- Traditional temple architecture.
- Royal maroon, antique gold, ivory and sandstone.
- Authentic Lord Jagannath artwork.
- Traditional Indian ornamental borders.

WEBSITE STRUCTURE:

Create seven sections/routes:

1. Personalized invitation.
2. Shrimad Bhagwat Katha program.
3. Pilgrimage destinations and detailed darshan information.
4. Accommodation and travel arrangements.
5. Chief guests.
6. Distinguished guests.
7. Important instructions, contact details and video gallery.

DESTINATION INTERACTIONS:

Each destination should have:
- Large photograph.
- Hindi title.
- Detailed description.
- Religious and historical significance, where verified.
- Address.
- Google Maps directions.
- Additional photographs.

Create reusable destination detail modals/cards without duplicating code.

PERSONALIZATION:

The same website will serve approximately 100 or more invitees.

Only the name on the first invitation screen should change.

Use a simple static URL parameter:
 /invite?to=GuestName

Read the name from the URL and display it safely.

Create a separate local utility to generate invitation links from a text list.

Do not create a public guest directory.
Do not store or collect visitor information.
Do not add RSVP or form functionality.

CONTENT MANAGEMENT:

Keep static event content in concise, consolidated data files without creating unnecessary files:
- katha.ts
- destinations.ts
- accommodation.ts
- guests.ts
- videos.ts
- instructions.ts

Use placeholders only for information not yet supplied. Do not invent daily Katha topics.
